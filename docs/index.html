关于本项目

基于上游 krkr2 重构的独立项目，专注移动端（iOS + Android）。

🎮

原生兼容

完全兼容原版 KiriKiri2 游戏脚本，内置高精度 TJS2 解析器，支持 PSB 动画与 Live2D Cubism 扩展。

⚡

零拷贝渲染

ANGLE 离屏渲染（iOS/macOS Metal 后端、Android Vulkan 后端），经 IOSurface / SurfaceTexture 零拷贝直达 Flutter 纹理，低功耗告别卡顿。

📱

移动优先

iOS 与 Android 为主目标，macOS 保留为 Apple 开发/调试平台。无 Mac 也能在 Windows 上构建 Android APK。

发布状态

iOS 测试版里程碑。当前处于预发布阶段。

平台状态说明
iOS 🔜 测试版 · 预发布 可构建无签名 IPA，经 AltStore / Sideloadly 侧载测试；存档目录已支持，开机能正常进游戏（黑屏问题以探针在排查中）
Android 🚧 构建恢复中 arm64 依赖（glib 等 meson 端口）交叉编译修复后即可出 APK
macOS ✅ 开发目标 Apple 平台开发/调试用

平台支持（技术形态）

引擎以不同二进制形态接入 Flutter 壳。

平台图形后端纹理共享引擎形态
iOS Metal IOSurface 静态库链接进 Runner
Android Vulkan SurfaceTexture libengine_api.so 打包进 APK
macOS Metal IOSurface dylib 打包进 Frameworks

快速开始

iOS 在 macOS 上构建；Android 可在 Windows / macOS / Linux 上构建（需 NDK）。

$ ./build.sh ios release     # 构建 iOS（macOS + Xcode）
$ ./build.sh android debug   # 构建 Android APK（任意主机）
$ ./build.sh macos debug     # 构建 macOS（开发）
